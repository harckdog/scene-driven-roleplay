# Contributing

This repository documents a local, scene-driven RolePlay architecture. Keep contributions small, typed, and backed by offline tests where practical. Do not add private conversations, copyrighted game art or dialogue, API keys, model weights, or unreviewed character cards.

Clear module boundaries are useful, but they do not imply a required psychological state machine or multi-stage planner. Changes to Scene retrieval, Generator prompts, and Selector behavior should be proposed separately from documentation and packaging work. The author has not yet chosen a license for original code; contribution and redistribution terms need explicit agreement.
