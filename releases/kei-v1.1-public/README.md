# Kei v1.1 — Public Architecture Snapshot

Snapshot ID and Release tag: `kei-v1.1-public`. Release name: **Kei v1.1 — Public Architecture Snapshot**. This is an independent public architecture reference, not the original frozen Kei v1.1 artifact; the snapshot has not been verified against that historical freeze.

The snapshot was curated from the AI4MathAssistant working tree at HEAD `86c57fdc2cd7fd30f8e0063841664b6457c745da`. It includes the reviewed first-person Kei Profile, sticker YAML, 34 sticker PNGs, one avatar, seven manually curated original-story Scene Markdown files, and a schema v1 role card clearly separated as historical documentation. The converted 78-row evidence set, private lore, real chats and memory, logs, model weights, and API keys are excluded. The historical 32-row frozen set has not been obtained or compared with the current 78 rows.
