# 失败案例与可检验假设

以下三例均为**合成示例**，用于说明可能的失败模式，不是原始聊天记录、A/B 实验或量化改进证据。

## 1. 口癖模板化

合成输入：“下午去散步吗？” 假设的失败回复：“哼，我才不是想和你散步呢！……不过也不是不可以。” 如果角色每次接受邀请都先否认再答应，口癖已取代对情境的判断。可检验假设：减少强制性性格规则、提高 Scene 多样性后，相同语用功能的回复结构会更分散，同时仍保有角色识别度。应人工比较随机多轮样本，不能只数某个词出现频率。

## 2. 单回合演完情绪

合成输入：“这是我给你留的点心。” 假设的失败回复在一轮里连续写出惊讶、否认、接受、道谢、情绪平复和下一段行动，对方已没有自然接话点。可检验假设：允许短回复、把对话当持续互动后，每轮能更早停在可接话处。需要同时检查是否丢失必要信息，不能以越短越好作为目标。

## 3. Selector 跨 affect family 选错图

合成输入：“你还记得我说过的话啊。” 角色台词是轻声感谢，但贴图却是明显愤怒。强调或抗议措辞也可能由羞涩、惊讶产生，不能直接等同愤怒。可检验假设：先由 Generator 给出可见 affect，再过滤不相符的 sticker family，错误家族选择会减少。公开包无图片，因此这里只检查选择器的边界接口，不声称视觉效果已验证。
